DSi Calendar

A calendar application for the Nintendo DSi

Setup Guide

Follow these steps to install DSi Calendar on your system using the package manager:

  1. Install the package manager host via ndspkg-host.
  2. Connect your Nintendo DSi to your PC via ftpd.
  3. If the default repository is not set up, use the following URL:
    https://github.com/raw/refs/heads/main/index.json
  4. Run ndspkg.py on your PC and execute the install command:
    install dsicalendar (Use lsp to search if it cannot be found)
  5. Wait for the installation to finish and reboot your console!
